Como pôr no Outlook

  1. Outlook na Web e novo Outlook: Definições (roda dentada) → Contas → Assinaturas → Nova assinatura. Dê-lhe o nome "ML Seguros", cole com Cmd+V (Mac) ou Ctrl+V (Windows) e guarde.
  2. Na mesma página, escolha-a como predefinida para as mensagens novas e para as respostas e reencaminhamentos. Guarde outra vez.
  3. Outlook para Mac: menu Outlook → Definições → Assinaturas → +.
  4. Outlook clássico no Windows: Ficheiro → Opções → Correio → Assinaturas → Nova.

O logótipo roda no Outlook na Web, no novo Outlook, no Outlook para Mac, no Gmail e no iPhone. No Outlook clássico do Windows fica parado. As imagens vêm do site da ML (mlseguros.pt/email/): se mudarem de sítio, as assinaturas ficam sem elas.
